# บทสวดก่อนนอน (Bedtime Chant)

เว็บแอปสำหรับเปิดสวดมนต์ก่อนนอนบนมือถือ ตัวอักษรเลื่อนขึ้นเองอัตโนมัติ มีโหมดมืด และติดตั้งลงหน้าจอโฮมได้แบบ PWA ใช้งานออฟไลน์ได้

**เปิดใช้งาน:** https://bedtime-chant.vercel.app

## บทสวดในแอป

- บทสวดอิติปิโส (พุทธคุณ ธรรมคุณ สังฆคุณ)
- ธัมมจักกัปปวัตตนสูตร (พร้อมบทขัด)
- พาหุง มหากา (ชัยมงคลคาถา) ต่อด้วยมหาการุณิโก
- พระคาถาชินบัญชร ต่อด้วยบทแผ่เมตตา

ข้อความบทสวดตรวจทานกับหนังสือ "มนต์พิธี" และแหล่งเผยแพร่ทั่วไป

## ความสามารถ

- เลื่อนตัวอักษรอัตโนมัติ ปรับความเร็วได้ 10 ระดับ แตะที่ข้อความเพื่อหยุด/เล่นต่อ
- ไล่สีข้อความตามจังหวะอ่านแบบคาราโอเกะ (เปิด/ปิดได้)
- ตั้งจำนวนรอบต่อบท (1–108 รอบ) พร้อมตัวบอกรอบที่กำลังอ่าน
- ปุ่มนับรอบด้วยมือ ลอยอยู่มุมขวาล่าง
- บันทึกการสวดต่อเนื่อง 90 คืน พร้อมปฏิทินและสถิติ สำรอง/นำเข้าข้อมูลเป็นไฟล์ JSON ได้
- ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage) ไม่ส่งไปที่เซิร์ฟเวอร์ใด

## โครงสร้างโปรเจกต์

```
web/
  index.html            แอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว ไม่มีขั้นตอน build)
  sw.js                 service worker สำหรับใช้งานออฟไลน์
  manifest.webmanifest  ข้อมูล PWA
  icons/, img/          ไอคอนและรูปภาพ
  vercel.json           header สำหรับ Vercel
  _headers              header สำหรับ Netlify
```

## รันบนเครื่อง

ไม่ต้องติดตั้งอะไรเพิ่ม เปิดเซิร์ฟเวอร์ไฟล์ธรรมดาในโฟลเดอร์ `web` แล้วเข้า http://localhost:8000

```bash
python -m http.server 8000 --directory web
```

service worker ทำงานบน `localhost` และ `https` เท่านั้น

### อยากเพิ่มบทสวดใหม่

เพิ่มได้โดยไม่ต้องแก้โค้ดส่วนอื่น บทสวดทั้งหมดเก็บเป็นข้อมูลในตัวแปร `CHANTS` ใน `web/index.html` เพิ่มบทใหม่เข้าไปหนึ่งรายการ แล้วแอปจะสร้างแท็บ ปุ่มตั้งจำนวนรอบ ปุ่มนับรอบ และปุ่มในหน้าบันทึกให้เอง

ขั้นตอนโดยละเอียด ตัวอย่างโค้ด และสิ่งที่ต้องแนบมาใน PR อยู่ที่ [CONTRIBUTING.md › การเพิ่มบทสวดใหม่](CONTRIBUTING.md#การเพิ่มบทสวดใหม่)

บทที่อยากให้มี ถ้ายังไม่สะดวกทำ PR เอง เปิด Issue บอกชื่อบทและแหล่งอ้างอิงไว้ได้เลย
